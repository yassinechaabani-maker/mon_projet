# mon_projet
A travers ce projet on sert à réaliser une Analyse Exploratoire de Données (EDA) sur un jeu de données réel

## Organisation du dépôt

- **R/** : contient les scripts R utilisés pour les analyses.
- **data/** : contient les données utilisées dans le projet.
- **figures/** : contient les graphiques générés.
- **poster/** : contient le poster de présentation du projet.

## Outils utilisés

- R
- Git
- GitHub
- Visual Studio Code
